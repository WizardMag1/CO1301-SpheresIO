TL-Engine11 1.0 Alpha6 ReadMe
=============================

This is an early access release of the new TL-Engine
Please read the "TL-Engine11 Experimental Readme.txt" file for detailed info


Quickstart
----------

- Install the TL-Engine11. The default settings are fine

- From the 'Start' menu type TL11 and choose "Create New TL11 Project...'
  - Make sure to choose TL11, not the original TL-Engine

- In the wizard that appears select the appropiate Visual Studio. Then choose a
  name for your new project and browse to a location for it.

- Press OK and your new project will be launched in Visual Studio. Open
  'Solution Explorer'. Here you can see the files in the project.

- Download the teaching materials from the UCLan Blackboard pages for tutorials
  on how to develop programs with the engine.


Installation Requirements
-------------------------

Windows 10 (Creators Update or above) or Windows 11
Microsoft Visual Studio 2022 or higher. The Community edition is free

The TL-Engine can be installed on a standard UCLan machine by using the
default installation location


Please report installation problems / bugs to lsnoel@uclan.ac.uk
