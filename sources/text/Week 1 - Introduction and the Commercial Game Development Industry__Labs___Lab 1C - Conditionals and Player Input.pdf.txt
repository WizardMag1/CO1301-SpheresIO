2. The “if” statement (Read only) 
a. Selection is the ability to execute code only if some condition is met (e.g., execute a block 
of code if the condition is true, or not execute a block of code if the condition is not true.  
b. In C++, you can exercise this control through the use of the word "if" . The general form of 
an if statement is: 
if (condition) 
{ 
// conditional execution 
} 
c. The condition is a programming statement which equates to either true or false. Any 
expression which equates to a number can also be used. 
d. The following are examples of the use of the if statement: 
 
if ( a == b ) //if the first Variable is equal to the second Variable 
{ 
// do something 
} 
if ( a != b ) //if the firstVariable is not equal to the secondVariable 
{ 
// do something 
} 
if ( a < b ) //if the firstVariable is less than the secondVariable 
{ 
// do something 
} 
if ( a > b ) //if the firstVariable is greater than the secondVariable

{ 
// do something 
} 
if ( myEngine->KeyHit( [KeyCode] )) //if the key with the provided keycode is hit 
{ 
//do something 
} 
if (!myEngine->KeyHeld( [KeyCode] )) //if the key with the provided keycode is 
NOT held (notice the use of !) 
{ 
//do something 
} 
if ( a + b < c) //if the sum of the firstVariable and secondVariable is less than 
the thirdVariable 
{ 
// do something 
} 
if ( a * b > 100) //if the product of the firstVariable and secondVariable is 
greater than 100 
{ 
// do something 
} 
 
e. Note that a conditional statement does not execute a command, but is used to make 
decisions about executing commands. 
 
3. Checking for Player Input 
a. The 3D engine monitors the keyboard and mouse input for its own window. We can ask 
the engine if particular keys or mouse buttons have been pressed; the methods to do this 
are: 
 
bool KeyHit( EKeyCode ); // Returns true when a given key or button is first pressed down. 
 
// Example usage: if (myEngine->KeyHit( Key_A )) { Do something } 
bool KeyHeld( EKeyCode ); // Returns true as long as a given key or button is held down. 
 
// Example usage: if (myEngine->KeyHeld( Mouse_LButton )) { Do something } 
 
Note: The above code snippets show the method’s signatures – the return type of the 
method (bool in both cases), the method name (e.g. KeyHit), and the parameter type 
(EKeyCode). You should not copy the method signature into your program (otherwise the 
compiler will think you are trying to redefine the methods!). When you call the methods, you 
can assign the result to a variable of the correct return type or, since the return type is bool, 
use the method call as the condition in an "if" statement, and you must pass in a parameter 
of the required type. The examples provided as comments show how the methods are used.

b. You must supply a special key code to indicate which key (or button) you want to test 
("Key_A" and "Mouse_Lbutton" were used in the examples above). Th e full list of key

c. Notice that mouse buttons are considered to be "keys" also. 
d. There is a slight difference between the two input methods provided above. The first

let go of the key and press it again.  
e. The second method ("KeyHeld") will always return true as long as the key is held down.
