Module Content
The module is separated into four thematic areas:
The computer game industry: Commercial game design and development, sales, rating, censorship, etc.
Game Mechanics: Gameplay, Game Balance, etc.
Game Development Concepts: Game loop, User Input, Collision Detection, etc.
Mathematics for Game Development: Trigonometry, Vectors, Matrices, etc.
--- slide 4 ---
Learning Objectives
On successful completion of this module, you will be able to:
Describe key game concepts.
Critique a game design with reference to published games.
Use a game engine to create a simple computer game prototype.
Apply mathematical techniques for analysis and reasoning about problems

Module Delivery
Lectures: 2h lectures that will cover the theoretical aspects of games

Additional Materials: periodically, additional materials in the form of YouTube videos, LinkedIn Learning courses, Tutorial Videos, Websites, Magazines, etc.
--- slide 9 ---
Labs
You will be using C++ to write code for a game engine specifically built at  UCLan to teach game programming, the TL-Engine.
You will find the TL-Engine installed on the lab computers you will be working on.
Each lab has mandatory exercises for you to complete.
Most labs also have additional exercises for you to complete either in the lab or in your own time (optional).
Completing these exercises will put you in a very good position to excel in this module and in all your programming endeavors.
--- slide 10 ---
Working at Home
You will need to install the TL-Engine and Visual Studio on your PC to be able to participate in remote labs.
You need to have a Windows PC to be able to install it.
If you are a MAC user, you will need a Virtual Machine to run Windows.
Instructions to help you through installing the TL-Engine are available on Blackboard.
