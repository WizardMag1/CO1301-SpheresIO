2. Vectors in Game Development 
1. Vectors are used throughout game development as a way of describing movement or direction. 
In 3D, a vector is simply three numbers: x, y , and z, written between round brackets and 
separated by commas. The first number is the x value; the second number is the y value; the 
third value is the z value. However, these numbers now represent movement or direction 
instead of location. To calculate the vector between two points at position P1 and P2, you must 
subtract the x, y, and z components of P1 from the x, y, and z components of P2. Note that this 
is not the same as the vector from P2 to P1 . To calculate this second vector, you will need to 
subtract the x, y, and z components of P2 from the x, y, and z components of P1.  As mentioned 
earlier, vectors can also be used to represent movement. A vector used for moving an object 
specifies the units along x, y, and z that the object should be moved every frame.

4. An array of Models 
1. An array is a way of referring to a group of variables by a single name. The elements of an 
array can be initialized when the array is declared, or they can be assigned values after the 
array has been declared. Examples of array declaration and initialization are given below (do 
not copy this code into your project). 
int primeNumbers[3];  //an integer array of size 3 is declared but not initialised 
primeNumbers[0] = 1;  //the first element of primeNumbers is assigned a value of 1 
primeNumbers[1] = 3;  //the second element of primeNumbers is assigned a value of 3 
primeNumbers[2] = 7;  //the third element of primeNumbers is assigned a value of 7 
 
//an integer array of size 4 is declared and initialised 
int evenNumbers[4] = {2, 4, 6, 8};  
 
//a string array of size 5 is declared and initialised 
string sonyConsoles[5] = {"PS1", "PS2", "PS3", "PS4", "PS5"};  
 
// IModel* array of size 10 declared but not initialised 
IModel* particleModels[10]; 
2. The usefulness of arrays is that we can refer to the group of variables by just using their array 
name. The individual variables still exist and can be referenced using the array index, a 
number inside square brackets. For example, if I wanted to reference the first element of the 
IModel* array given above, I could write: 
IModel* particles[0] = particleMesh->CreateModel(); 
The array index always starts at 0. In other words, the first element of the array is always at 
0. This means that the last element of the array is one less than the size of the array. In

other words, the last element of an array of size 10 is array index 9. If I wanted to reference 
the last element of the IModel* array given above, I could write: 
IModel* particles[9] = particleMesh->CreateModel(); 
If you go over the edge of an array, you will cause a run-time error. 
3. You can loop through the elements of an array using a for-loop. This is useful for assigning 
values to elements as well as accessing elements. For example, the code below will create a 
model using particleMesh and assign it to each element of particleModels. 
for (int i = 0; i <= 9; i++) 
{ 
    particleModels[i] = particleMesh->CreateModel(); 
}
