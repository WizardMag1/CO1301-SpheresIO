Solutions: 
 
1a) P1P2, i.e. the vector between P1 and P2  
P1 = ( 50, 50, 50)  
P2 = (-11, 22, -33)  
P1P2 = P2 - P1 = (P2x – P1x, P2y – P1y, P2z – P1z)  
P1P2 = (-11 – 50, 22 – 50, -33 -50)  
P1P2 = (-61, -28, -83)  
1b) P2P1, i.e. the vector between P2 and P1  
P1 = ( 50, 50, 50)  
P2 = (-11, 22, -33)  
P2P1 = P1 – P2 = (P1x – P2x, P1y – P2y, P1z – P2z)  
P1P2 = (50 – (-11), 50 - 22, 50 – (-33))  
P1P2 = (61, 28, 83)  
1c) AB, i.e. the vector between A and B  
A = (3, 4, 5)  
B = (5, 7, 9)  
AB = B – A = (Bx – Ax, By – Ay, Bz – Az)  
AB = (5 – 3, 7 – 4, 9 – 5)  
AB = (2, 3, 4)  
1d) DC, i.e. the vector between D and C  
C = (10, 20)  
D = (34, 50)  
DC = C – D = (Cx – Dx, Cy -Dy, Cz – Dz)  
DC = (10 – 34, 20 -50, 0 - 0)  
DC = (-24, -30) or (-24, -30, 0)  
1e) BC, i.e. the vector between B and C  
B =(5, 7, 9)  
C = (10, 20)  
BC = C – B = (Cx – Bx, Cy – By, Cz – By)  
BC = (10 – 5, 20 – 7, 0 – 9)  
BC = (5, 13, -9)
