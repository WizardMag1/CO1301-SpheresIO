The Direction Vector 
1. You have derived the vector between the enemyDrone and playerDrone. You have also

2. The direction vector is independent of the distance between two points. For example, it allows 
you to move a model in a particular direction , disregarding the speed of the movement. If the 
vector between the two positions is v (x, y, z), and the length of this vector is " len" , then the 
direction vector is (x/len, y/len, z/len) 
3. To calculate the direction vector from enemyDrone to playerDrone, first create three new float 
variables: directionX, directionY, and directionZ. Then use the variables to store the 
components of your direction vector as shown below: 
//sum of the squares of the vector's components  
float distance = distanceX + distanceY + distanceZ;  
distance = sqrt( distance ); // the square root of distance  
float directionX = vectorX / distance;  
float directionY = vectorY / distance;  
float directionZ = vectorZ / distance; 
4. Check that you are dividing each vector component by the distance and not, for example, 
distanceX by distance.

Introducing Variable Timing 
1. You may have noticed that the speed of the objects in your game reduces when you introduce 
additional models or perform complex operations every frame. You may have also noticed that 
the same program runs at different speeds when executed on different machines , e.g., the 
games lab PC vs your PC. This is because so far, you have been moving models every frame by 
a given amount of units, and the number of frames per second rate of your program depends on 
the type of machine you have as well as the complexity of the program. In this section, you will 
learn to create consistent programs using variable timing. 
2. The first step is to initialize the timer by adding the code below in the initialization section of 
your program. 
myEngine->Timer(); 
3. You then need to call Timer() once per frame, at the beginning of the game loop, immediately 
after myEngine->DrawScene();. Declare a variable of type float called frameTime and assign 
the value returned by Timer() to it; this value represents the time taken in ms for the last scene 
to be rendered.

if (myEngine->KeyHeld(Key_W))

  playerDrone->MoveLocalZ(kDroneSpeed * frameTime);

if (myEngine->KeyHeld(Key_A))

else if (myEngine->KeyHeld(Key_D))

  playerDrone->RotateLocalY(kDroneSpeed* frameTime / 2);

This essentially means that your objects now have a velocity of units/second; for example, the 
playerDrone is now moving at a speed of 50 units/second regardless of the machine type or
